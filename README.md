# 📚 Social Book Store

The **Social Book Store** is a social bookstore based on Spring Boot, where users can upload and exchange books for free.

### Requirements

- Java 17+
- Maven
- MySQL 

### Installation instructions

1. clone repository
   ```sh
   git clone https://github.com/gianniskokkinis/Social-Book-Store.git
   cd social-book-store
   ```

2. Setup Database (MySQL)

3. Update the credentials from `application.properties` to your Database credentials.

4. Run as Java Project

5. Open a browser and run `http://localhost:8080`
